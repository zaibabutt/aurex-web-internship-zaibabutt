# 🚀 React Task Manager (Part 1)

A professional and clean **Task Manager (To-Do List)** application built using **React.js** and **Vite** for the Aurex Web Internship Program (Month 2).

## ✨ Key Features
- **Add New Tasks:** Users can add multiple tasks with input validation.
- **Toggle Status:** Mark tasks as completed (strikes through text) or undo them easily.
- **Delete Tasks:** Instantly remove any task from the list.
- **Component-Based Architecture:** Modular design using reusable components.

## 🛠️ Tech Stack & Structure
- **Frontend:** React.js, JavaScript (JSX), HTML5
- **Build Tool:** Vite

### 📁 Project Folders Included:
- `src/components/Header.jsx` — Clean title banner.
- `src/components/TaskForm.jsx` — Form with state handling to create tasks.
- `src/components/TaskItem.jsx` — Individual task row with actions.
- `src/components/TaskList.jsx` — Renders list dynamically or displays an empty state message.
- `src/App.jsx` — Main parent file controlling state and CRUD functions.
